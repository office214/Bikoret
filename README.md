# ביקורת נוכחות — אפליקציה

אפליקציית ווב לביצוע ביקורת נוכחות מהטלפון או מהמחשב.
האפליקציה נוספת **לתוך פרויקט הסקריפט הקיים** של הקובץ "ביקורת" ומשתמשת בפונקציות שלו:
סנכרון מהמסד המרכזי, הכנת ביקורת, סגירת ביקורת, גיליונות הדפסה ו-SMS דרך 019.
הקוד הקיים והתפריט בגיליון ממשיכים לעבוד כרגיל.

## קבצים

| קובץ | מה זה |
| --- | --- |
| `apps-script/WebApp.gs` | צד השרת של האפליקציה (כל הפונקציות מתחילות ב-`app`) |
| `apps-script/Index.html` | המסך |

## מה יש באפליקציה

- **ביקורת** — רשימת התלמידים לפי א"ב, ולכל אחד 5 כפתורים: נוכח · בישוב · חסר · לא ענה · נרשם.
  מי שלא ענה מסומן ב-⚠. מונים בראש המסך (לחיצה = סינון), חיפוש, ביטול סימון, רענון אוטומטי כל 15 שניות.
- **תוצאות** — כל הביקורות מהמסד, פירוט מי לא היה בכל ביקורת, והיסטוריה אישית לתלמיד.
- **הדפסה** — שער / כללי / חסר-לא ענה / בישוב / נרשם, ועדכון גיליונות ההדפסה בקובץ.
- **ניהול** — הכנת ביקורת (בוקר/צהריים + סוג), סמס התחלה / סמס לא ענו (עם סיסמה), פרטי ביקורת וסגירה,
  סנכרון מסד, והגדרות SMS.
- נגישות: ניגודיות גבוהה, כפתורים גדולים, ניווט מקלדת, הגדלת גופן, מצב כהה.

## התקנה (פעם אחת)

1. לפתוח את הקובץ "ביקורת" במחשב (או בכרום בטלפון במצב "אתר למחשב") ← **תוספים ← Apps Script**.
2. **תיקון בקוד הקיים** (בקובץ הקוד הקיים, בתוך `CONFIG`): בגיליון התאים C1:E1 ממוזגים, השעה נמצאת ב-F1 והסוג ב-G1.
   לשנות שתי שורות:
   ```js
   CELL_TIME: 'F1',
   CELL_TYPE: 'G1',
   ```
   (בלי התיקון השעה לא נשמרת בסגירת ביקורת, וסוג הביקורת נקרא כ"11:00" — כפי שקרה בביקורות 153–154.)
3. ➕ ליד "קבצים" ← **סקריפט** ← שם: `WebApp` ← להדביק את `apps-script/WebApp.gs`.
4. ➕ ← **HTML** ← שם: `Index` ← להדביק את `apps-script/Index.html`.
5. לשמור, ואז **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**:
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל מי שב-kiryatmoshe.co.il** (או "רק אני")
6. לאשר הרשאות ולשמור את הקישור (מומלץ להוסיף למסך הבית בטלפון).

> אחרי כל שינוי בקוד: **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה**, כדי שהקישור יקבל את השינוי.

## הגדרות SMS

הפרטים של 019 נשמרים ב-Script Properties של הפרויקט — לא בקוד ולא בגיליון.
אם הם כבר מוגדרים בפרויקט (הקוד הקיים משתמש בהם), אין צורך לעשות כלום.
לעדכון: באפליקציה ← **ניהול ← הגדרות SMS** (רק מי שפרס את האפליקציה יכול לשנות),
או ב-Apps Script ← ⚙️ הגדרות הפרויקט ← מאפייני סקריפט:
`SMS019_TOKEN`, `SMS019_USERNAME`, `SMS019_SOURCE`, `ADMIN_REPORT_PHONE`.
להרשאת עריכה למשתמשים נוספים: מאפיין `APP_ADMINS` עם כתובות מייל מופרדות בפסיק.

## תצוגה מקדימה

פתיחת `apps-script/Index.html` ישירות בדפדפן מציגה את האפליקציה עם נתוני דוגמה.
