# ביקורת נוכחות — אפליקציה

אפליקציית ווב (Google Apps Script) לביצוע ביקורת נוכחות בישיבה, מהטלפון או מהמחשב.
האפליקציה עובדת ישירות על הקובץ **"ביקורת"** בגוגל דרייב ושומרת על המבנה הקיים שלו:

| גיליון | תפקיד באפליקציה |
| --- | --- |
| **פורמט** | הביקורת הפעילה — המסך הראשי של האפליקציה. כל סימון נכתב מיד לתיבות הסימון בגיליון. |
| **מסד** | תוצאות כל הביקורות. בסגירת ביקורת נוספת עמודה חדשה (F) עם הסיכום והסטטוס של כל תלמיד. |
| **הדפסה …** | גיליונות ההדפסה מתעדכנים אוטומטית בסגירת ביקורת (3 הביקורות האחרונות). |

## מה יש באפליקציה

- **✅ ביקורת** — רשימת התלמידים לפי א"ב, ולכל תלמיד 5 כפתורים גדולים: נוכח · בישוב · חסר · לא ענה · נרשם.
  - מונים בראש המסך (לחיצה על מונה = סינון), חיפוש לפי שם, אחוז נוכחות חי.
  - כפתור "כל הלא ענה ← נוכח" לסיום מהיר.
  - כל סימון נשמר מיד, ואפשר לבטל ("בטל" בהודעה שקופצת).
  - כמה אנשים יכולים לסמן במקביל — המסך מתרענן כל 15 שניות.
- **📊 תוצאות** — טבלת כל הביקורות (תאריך, שעה, סוג, חסר/נרשם/בישוב/לא ענה, אחוז, עובר/נכשל).
  לחיצה על ביקורת מציגה מי לא היה נוכח. חיפוש תלמיד מציג את ההיסטוריה האישית שלו.
- **🖨️ הדפסה** — שער / כללי / חסר-לא ענה / בישוב / נרשם, לבחירת 1–5 ביקורות אחרונות, והדפסה ישירה.
- **⚙️ ניהול** — הכנת ביקורת בוקר / צהריים, פרטי ביקורת (תאריך עברי, שעה, סוג), סגירת ביקורת.
- נגישות: כפתורים גדולים, טקסט ולא רק צבע, ניווט מקלדת (חיצים), הגדלת גופן (א+), מצב כהה.

## כללי חישוב (כמו בקובץ הקיים)

- **הכנת ביקורת בוקר**: כל מי שבמסד מסומן "תלמיד" או "חצי יום בוקר". **צהריים**: "תלמיד" או "חצי יום צהריים".
- **אחוז נוכחות** = (מס' תלמידים − חסר − נרשם − לא ענה) ÷ מס' תלמידים.
- **עובר** מ־85% ומעלה (הסף נקבע לפי התוצאות שבמסד; ניתן לשנות ב־`PASS_THRESHOLD` בקובץ `Code.gs`).

## התקנה (פעם אחת, כ־5 דקות)

1. להיכנס ל־<https://script.google.com> עם חשבון שיש לו **הרשאת עריכה** לקובץ "ביקורת" → **פרויקט חדש**.
2. להעתיק את התוכן של `apps-script/Code.gs` לקובץ `Code.gs` בפרויקט.
3. ליצור קובץ HTML חדש (➕ ← HTML) בשם **`Index`** ולהעתיק אליו את `apps-script/Index.html`.
4. (רשות) בהגדרות הפרויקט לסמן "הצג קובץ מניפסט appsscript.json" ולהעתיק את `apps-script/appsscript.json`.
5. **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**:
   - "הפעלה בתור": **אני**
   - "למי יש גישה": **כל מי שב־kiryatmoshe.co.il** (או "רק אני")
6. לאשר את ההרשאות, ולהעתיק את הקישור שמתקבל. מומלץ להוסיף אותו למסך הבית בטלפון.

> הפרויקט נפרד מהסקריפט הקיים שבתוך הגיליון, כך ששום דבר קיים לא נשבר — התפריט וההודעות (SMS) בגיליון ממשיכים לעבוד כרגיל.

## תצוגה מקדימה

פתיחת `apps-script/Index.html` ישירות בדפדפן מציגה את האפליקציה עם נתוני דוגמה (בלי חיבור לגיליון).
