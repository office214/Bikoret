# ביקורת נוכחות

אפליקציית Next.js (Vercel) לביקורת נוכחות בישיבה — https://bikoret-gray.vercel.app

- **תלמידים** — נקראים בכל הכנת ביקורת מגליון "תלמידים" במסד המרכזי (Google Sheets, קריאה בלבד),
  לפי אותם כללים של הסקריפט הישן: תלמוד 00/02, מצב לימודים (תלמיד / תלמיד - בוקר בלבד / תלמיד - צהריים בלבד / ר"מ),
  וסינון לפי מוסד בביקורת חיצונית. הטלפון והשפה נלקחים מאותה שורה.
- **תוצאות** — נשמרות ב-Postgres: ביקורת = שורה, וכל תלמיד בביקורת = שורה. אין יותר הוספת עמודות לגיליון.
- **SMS** — 019, בקבוצות (בקשה אחת לכל נוסח), עם יומן שליחה והגנה משליחה כפולה.
- **כניסה** — Google, רק חשבונות הדומיין או רשימת מיילים.

## איך עובדים

1. מסך הבית: **ביקורת פנימית / ביקורת אמת 00 / ביקורת אמת 02**. לחיצה פותחת ביקורת מיד.
2. בוקר/צהריים נקבע לפי השעה (בוקר 08:30–14:00, צהריים 14:00–17:30; מחוץ לשעות — לפי הקרוב).
3. מיד אחרי הפתיחה: "לשלוח הודעת פתיחת ביקורת?". כפתור "ללא ענו" זמין כל הזמן בראש המסך.
4. **מצב בדיקת SMS** (ניהול ← הגדרות מערכת): כל שליחה שולחת הודעה לדוגמה אחת לכל נוסח רק למספר הבדיקה — תלמידים לא מקבלים כלום.

## התקנה ב-Vercel

1. **מסד נתונים:** בפרויקט ב-Vercel ← Storage ← Create Database ← Neon ← Connect. `DATABASE_URL` נוסף לבד, והטבלאות נוצרות בהפעלה הראשונה.
2. **Google:** ב-[Google Cloud Console](https://console.cloud.google.com/apis/credentials) (מחובר כ-office@kiryatmoshe.co.il):
   - להפעיל את **Google Sheets API**.
   - OAuth consent screen ← **Internal**.
   - Create credentials ← OAuth client ID ← Web application ←
     Authorized redirect URI: `https://bikoret-gray.vercel.app/api/auth/callback`
   - להעתיק את Client ID ו-Client secret ל-Vercel כ-`GOOGLE_CLIENT_ID` ו-`GOOGLE_CLIENT_SECRET`.
3. **Redeploy**, להיכנס, ובלשונית **ניהול**:
   - "חיבור למסד התלמידים" — מאשרים קריאה בלבד לגיליונות.
   - "ייבוא היסטוריה" — מייבא את 154 הביקורות מגליון "מסד" (פעם אחת; הפעלה חוזרת לא משכפלת).
   - הגדרות SMS — טוקן 019, שם משתמש, שולח וטלפון מנהל (נשמר מוצפן).

## פיתוח מקומי

```bash
npm install
cp .env.example .env.local   # DATABASE_URL + AUTH_SECRET
# אופציונלי לבדיקות: DEV_AUTH_EMAIL=you@... (עוקף כניסה, רק מחוץ לפרודקשן), SMS_DRY_RUN=1
npm run dev
```
